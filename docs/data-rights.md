# データ取得方針

確認日: 2026-11-17

## 使用する提供元

[Sumo API](https://sumo-api.com/) の[公開APIガイド](https://sumo-api.com/api-guide)は無料でのアクセスを案内しています。APIによる事実データの取得に切り替え、氏名・番付・部屋・出身地・生年月日・身長・体重・通算成績の必要項目だけを保存します。画面に提供元リンク、取得日時、提供元更新日を表示します。

この判断は日本相撲協会による許諾取得やAPI全データの包括的ライセンス確認を意味しません。Sumo APIのホームにはサイト利用者向けの連絡案内もあります。問い合わせは送信していません。

## 取得方法

- 現役一覧 `GET /api/rikishis?limit=1000&skip=0&intai=false`
- 各力士の通算成績 `GET /api/rikishi/{id}/stats`
- 並列取得なし。既定でリクエスト間隔1秒、エラー・429で再試行せず停止。
- 一覧のtotalと取得数を照合し、全成績取得後に品質検証。失敗時は既存スナップショットを維持。
- 写真、紹介文、HTMLは取得・掲載しない。公式プロフィールURLは参照リンクのみ。
- 自動定期更新なし。更新は手動実行。

## 前版の調査記録

前版では日本相撲協会サイトを直接調査し、プロフィールが429を返したため追加アクセスを停止していました。今回は公式本体への巡回を再開せず、別提供元が公開するAPIを使用します。前版の「架空データ限定」実装は今回の実データ対応に置き換えています。
