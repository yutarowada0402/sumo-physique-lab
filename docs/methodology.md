# 集計方法

Sumo APIの現役力士一覧と各力士の通算成績から作成した一時点のスナップショットです。番付・測定値の提供元更新日は力士ごとに異なります。取得日を現在場所の番付確定日や測定日とは扱いません。

BMI = kg / (cm/100)^2、生涯勝率 = 勝/(勝+敗)。休場は除く。0勝0敗はnull。平均勝率は有効力士の単純平均。平均・中央値・四分位は有効値のみ。四分位は(n−1)pの線形補間、箱ひげのひげは最小と最大。体重外れ値はQ1−1.5IQR未満又はQ3＋1.5IQR超。Pearson rは10有効ペア以上かつ両変数分散が正のときのみ。回帰線は各階級の最小二乗。

階級別サマリーは階級以外の共通フィルターを適用し、常に6階級を表示。各統計のnと除外件数は測定値ごとに異なり得る。文字列・非正測定値は指標から除外するが元レコードは保持、パイプライン検査に報告。常識範囲外の正数は警告して勝手に除外しない。

階級・年齢・対戦相手・在位年数等の交絡を調整しない記述統計であり、体格の大きさは筋力を意味しない。勝率は純粋な強さを意味せず、相関は因果を示さない。少数取組の高勝率に注意。時系列や過去番付を含まない。
